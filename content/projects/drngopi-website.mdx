## Meta-project

Đây là dự án đặc biệt: website **tự giới thiệu chính mình** là một AI-built project.

Toàn bộ codebase được viết bởi `personal-brand-agent` — một Claude AI agent chuyên trách xây dựng và bảo trì website này. Tôi (Dr.NgoPi) đóng vai trò **giám đốc sáng tạo**: đưa ra spec, review, và approve.

## Quy trình build

1. Viết design spec chi tiết (colors, layout, content)
2. Agent đọc spec và build từng component
3. Review design qua browser tool
4. Deploy lên Vercel

## Stack lý do chọn

| Layer | Lý do |
|-------|-------|
| Next.js 14 | App Router, SSG, SEO tốt, Vercel native |
| TypeScript | Type safety cho long-term maintenance |
| Tailwind CSS | Rapid prototyping, design system nhất quán |
| Framer Motion | Animations mượt, không nặng |
| MDX | Content = code, version controlled, no CMS |
| Vercel | Zero-config deploy, auto-deploy từ GitHub |

## Design system

Dark navy (#0a0f1e) + teal gradient (#0ea5e9 → #22d3ee) — lấy cảm hứng từ terminal và deep ocean.

## Bài học

Dự án này chứng minh rằng với spec đủ tốt, AI agent có thể deliver production-ready code. Vai trò của developer chuyển sang **AI-assisted architect**.
